## Installation

Toolzzz est publiée sur les stores officiels Chrome et Firefox. Pour la majorité des joueurs, l'installation tient en deux clics. Une procédure manuelle est aussi disponible si tu préfères installer une version précise depuis GitHub.

## Sur Chrome (et navigateurs Chromium)

L'extension fonctionne sur **Chrome**, **Edge**, **Opera**, **Brave** et toute autre variante basée sur Chromium.

1. Ouvre la page Toolzzz sur le Chrome Web Store : <!-- LIEN STORE À AJOUTER -->
2. Clique sur **Ajouter à Chrome** puis confirme l'installation.
3. Va sur [www.fourmizzz.fr](http://www.fourmizzz.fr) — la toolbar Toolzzz apparaît automatiquement à droite de la page (ou en bas si tu es sur écran étroit).

Aucune connexion ni configuration n'est nécessaire au premier lancement : tes paramètres seront créés automatiquement et stockés localement par ton navigateur.

> Astuce : épingle l'icône de l'extension à la barre Chrome (puzzle → punaise) pour la rendre plus visible. Tu n'en auras pas vraiment besoin pour utiliser Toolzzz, mais ça aide à vérifier qu'elle est bien active sur le domaine fourmizzz.fr.

## Sur Firefox

1. Ouvre la page Toolzzz sur Mozilla Add-ons (AMO) : <!-- LIEN STORE À AJOUTER -->
2. Clique sur **Ajouter à Firefox** puis confirme l'autorisation d'accéder à fourmizzz.fr.
3. Recharge l'onglet du jeu si tu en avais déjà un d'ouvert.

L'extension fonctionne sur **Firefox desktop** et **Firefox pour Android** (version 142 minimum sur mobile pour bénéficier de la déclaration de confidentialité). Sur les versions plus anciennes, le store affichera un avertissement mais l'extension reste fonctionnelle.

## Installation manuelle (depuis GitHub Releases)

Cette méthode est utile si tu veux **tester une version précise**, ou si l'extension a été retirée temporairement d'un store le temps d'une revue. Les artefacts publiés sur GitHub Releases sont strictement identiques à ceux soumis aux stores.

### Chrome / Chromium

1. Télécharge le fichier `toolzzz-X.Y.Z-chrome.zip` depuis la page [Releases](https://github.com/GuiEpi/toolzzz/releases).
2. Décompresse l'archive dans un dossier permanent (si tu le supprimes, l'extension sera désinstallée).
3. Ouvre `chrome://extensions/`, active **Mode développeur** en haut à droite.
4. Clique sur **Charger l'extension non empaquetée** et sélectionne le dossier décompressé.

### Firefox

L'installation hors store sur Firefox stable nécessite une version Developer Edition, Nightly, ou ESR avec `xpinstall.signatures.required = false`. Pour un usage normal, préfère le store AMO.

## Mise à jour

Quand tu installes via un store, les mises à jour se font automatiquement. À chaque nouvelle version, un toast `Toolzzz mis à jour` s'affiche au premier chargement d'une page Fourmizzz pour te le signaler.
