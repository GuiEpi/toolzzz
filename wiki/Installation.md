## Sur mobile

L'extension fonctionne aussi sur **Firefox pour Android** (Chrome Android ne supporte pas les extensions). Même lien AMO que sur desktop. Version 142+ recommandée pour bénéficier de la déclaration de confidentialité côté store.

## Installation manuelle

Utile si tu veux tester une version précise, ou si l'extension est temporairement absente d'un store. Les artefacts publiés sur [GitHub Releases](https://github.com/GuiEpi/toolzzz/releases) sont strictement identiques à ceux soumis aux stores.

### Chrome / Chromium

1. Télécharge `toolzzz-X.Y.Z-chrome.zip` depuis la page Releases.
2. Décompresse-le dans un dossier permanent (le supprimer désinstalle l'extension).
3. Ouvre `chrome://extensions/`, active **Mode développeur**, clique **Charger l'extension non empaquetée**, sélectionne le dossier.

### Firefox

L'installation hors store sur Firefox stable nécessite une édition Developer / Nightly / ESR avec `xpinstall.signatures.required = false`. Pour un usage normal, préfère AMO.

## Mise à jour

Les mises à jour passent automatiquement par les stores. À chaque nouvelle version, un toast `Toolzzz mis à jour` s'affiche au premier chargement d'une page Fourmizzz.
